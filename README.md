### 🚀 차기 게시판 개발 목표 및 요구사항

* **1단계 (DB 구축)**: 오라클 상시 무료 자율운영 데이터베이스(Autonomous DB) 생성 및 테스트 데이터 5개 주입
* **2단계 (환경 세팅)**: 내 컴퓨터 및 서버에 `oracledb` (DB 연동), `multer` (이미지 업로드) 패키지 설치
* **3단계 (백엔드 개발)**: 한글 깨짐 방지를 위한 [숫자+영문] 파일명 무작위 변경 규칙 및 글쓰기/수정/삭제 CRUD API 구현
* **4단계 (프론트엔드)**: 스마트폰 접속 시 앨범 선택 및 모바일 카메라 직접 촬영 업로드를 지원하는 반응형 게시판 레이아웃 제작
